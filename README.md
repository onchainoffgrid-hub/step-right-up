# Step Right Up

A free, mobile-first confidence tool for Florida scholarship filing families.

**Brand:** Critters on Call / Sheehan Homestead

## Modules

1. **Step Right Up** — short lessons, a 7-question quiz, filing checklist, and a link to the official Step Up for Students site.
2. **The Watch** — a tap game for clearing everyday family to-dos.

## Notes

- Static single-page site (`index.html`). Works offline once loaded.
- Confidence tool only — not the application and not legal advice. Always confirm details at [stepupforstudents.org](https://www.stepupforstudents.org/).
